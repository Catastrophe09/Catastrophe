# Catastrophe Website

A free, static website starter that can be published online with GitHub Pages.

## Customize the site

1. Edit `index.html` to replace the placeholder text, headings, links, and email address.
2. Edit `styles.css` to change colors, spacing, or layout.
3. Edit `script.js` if you want different navigation behavior.

## Run locally

Because this is a static website, you can open `index.html` directly in a browser. For a local web server, run:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Publish for free with GitHub Pages

1. Push this repository to GitHub.
2. In GitHub, open the repository settings.
3. Select **Pages** in the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your branch and the `/ (root)` folder, then save.
6. GitHub will provide a public website URL after the first deployment finishes.

## Files

- `index.html` contains the page content.
- `styles.css` contains the responsive visual design.
- `script.js` contains the mobile navigation and current-year footer behavior.
